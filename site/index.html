The overview

Know if your cluster is okay in two seconds.

Half-round gauges show real usage, and a thin inner arc shows what pods have reserved. You see the squeeze before new pods stop scheduling.

Features

Everything kubectl knows, without the typing.

Live by default

Lists and events update the moment the cluster changes. Gauges refresh every 15 seconds. No refresh button.

Logs and terminal

Follow live logs and open a terminal in any container, right from the browser.

Safe YAML edits

Edit the real object, see the diff, and dry-run it on the server before anything changes.

Your permissions, respected

Sign in with SSO, LDAP or a token. Buttons appear only for what your RBAC allows.

Custom resources and Helm

Any CRD works out of the box. Helm releases and a resource map per namespace are built in.

Dark first, light too

Easy on the eyes at 3am, readable in a bright meeting room. Fully keyboard friendly.

Install

Running in a minute.

Start on your laptop with your kubeconfig, then move it into the cluster when your team wants it.

Read the quick start
$ tar -xzf glowpod_*_darwin_arm64.tar.gz && cd glowpod_*_darwin_arm64 $ ./glowpod

Download glowpod for macOS, Linux or Windows (shown: a Mac with Apple silicon). It uses your kubeconfig's current context, listens on 127.0.0.1 only and opens your browser.

$ helm install glowpod oci://ghcr.io/baid0/charts/glowpod \ -n glowpod --create-namespace

Your team signs in with SSO (OpenID Connect), LDAP or a service-account token. Set up the address and ingress with the install guide.

$ git clone https://github.com/Baid0/glowpod $ cd glowpod && make build $ ./bin/glowpod

Needs Go and pnpm. The binary embeds the web app, so there is nothing else to run.
