Quick start

Run Glowpod on your own computer and see your cluster in about a minute. It uses the kubeconfig you already have, so there is nothing to install in the cluster.

Time
About 1 minute
You need
A working kubeconfig
Works on
macOS, Linux, Windows

Four ways to run Glowpod

For Runs on Signs in with Start
Local dashboard You, in the browser Your machine (127.0.0.1 only) Your kubeconfig glowpod
Terminal app You, in a terminal or over SSH Your machine Your kubeconfig glowpod term
In the cluster Your team The cluster, with Helm SSO, LDAP or a token, each person as themselves Helm guide
Hub (0.4.0+) Your company, many clusters One cluster, with Helm, or one docker run to try it (0.5.0+); others connect with an agent, like Rancher A Glowpod account, SSO or LDAP Hub guide

The first two are the same glowpod program and need nothing in the cluster. This page starts the local dashboard.

1Install Glowpod

One command installs the glowpod program: Homebrew on macOS and Linux, Scoop on Windows.

Terminal
# macOS and Linux $ brew install glowpod-dev/tap/glowpod # Windows (PowerShell) > scoop bucket add glowpod https://github.com/glowpod-dev/scoop-bucket > scoop install glowpod

Or get the file for your system and chip from the latest release and unpack it. If macOS blocks a program you downloaded that way, allow it once with xattr -d com.apple.quarantine ./glowpod.

2Open your cluster

Run Glowpod. It reads your current kubeconfig context, listens on 127.0.0.1 only and opens the dashboard in your browser with a one-time sign-in link.

$ glowpod Glowpod is running. Open: http://127.0.0.1:7171/…

Every context in your kubeconfig is listed on the Clusters page; switch from the cluster picker, or start with -context staging to open that one first. Every request runs as the context's user, so you see exactly what you can see with kubectl.

Gauges need metrics-server

The CPU and memory gauges read live usage from metrics-server. Without it they say "Install metrics-server" and everything else still works. Network appears only when Glowpod finds Prometheus.

$ kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml

3Pick your mode

Use the Glance and Deep tabs in the top bar. Glowpod remembers your choice.

Mode Best for You see
Glance Developers shipping apps Your apps, their health, plain-language problems
Deep Platform and DevOps teams Every resource, node load, events, YAML
