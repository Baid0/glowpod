Quick start

Run Glowpod on your own computer and see your cluster in about a minute. It uses the kubeconfig you already have, so there is nothing to install in the cluster.

Time
About 1 minute
You need
A working kubeconfig
Works on
macOS, Linux, Windows

1Download Glowpod

Get the file for your system and chip from the latest release and unpack it. Each one holds a single glowpod program.

Terminal
# macOS and Linux (here: Linux on Intel or AMD) $ tar -xzf glowpod_*_linux_amd64.tar.gz && cd glowpod_*_linux_amd64 # Windows: unzip glowpod_*_windows_amd64.zip, then in that folder > .\glowpod.exe

If macOS blocks a downloaded program, allow it once with xattr -d com.apple.quarantine ./glowpod.

2Open your cluster

Run Glowpod. It reads your current kubeconfig context, listens on 127.0.0.1 only and opens the dashboard in your browser with a one-time sign-in link.

$ ./glowpod Glowpod is running. Open: http://127.0.0.1:7171/…

Want a different cluster? Add -context staging. Every request runs as your kubeconfig's user, so you see exactly what you can see with kubectl.

Gauges need metrics-server

The CPU and memory gauges read live usage from metrics-server. Without it they say "Install metrics-server" and everything else still works. Network appears only when Glowpod finds Prometheus.

$ kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml

3Pick your mode

Use the Glance and Deep tabs in the top bar. Glowpod remembers your choice.

Mode Best for You see
Glance Developers shipping apps Your apps, their health, plain-language problems
Deep Platform and DevOps teams Every resource, node load, events, YAML
